# Benutzerhandbuch

Dieses Handbuch richtet sich an Personen, die Seurch **nutzen** – auf dem gehosteten Dienst unter [seurch.eu](https://seurch.eu/) oder auf einer Instanz, die jemand für Sie betreibt.

Seurch ist eine Metasuchmaschine: Sie geben eine Anfrage ein, und Seurch kombiniert Ergebnisse aus mehreren unabhängigen Quellen auf einer einzigen, übersichtlichen Seite. Es muss nichts installiert werden, es funktioniert in jedem modernen Browser und verfolgt Sie nicht.
