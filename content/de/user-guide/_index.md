# Benutzerhandbuch

Dieses Handbuch richtet sich an Personen, die Searpa **nutzen** – auf dem gehosteten Dienst unter [searpa.eu](https://searpa.eu/) oder auf einer Instanz, die jemand für Sie betreibt.

Searpa ist eine Metasuchmaschine: Sie geben eine Anfrage ein, und Searpa kombiniert Ergebnisse aus mehreren unabhängigen Quellen auf einer einzigen, übersichtlichen Seite. Es muss nichts installiert werden, es funktioniert in jedem modernen Browser und verfolgt Sie nicht.
